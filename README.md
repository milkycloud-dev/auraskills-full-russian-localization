## English

### Overview

This repository provides clean, standalone Russian localization files for **AuraSkills v2.4.0 (ArchyX)**.
It contains only configuration and text files to respect original author licensing and copyright requirements.

### Files

- `messages/messages_ru.yml`: Full Russian messages file with all 82 new v2.4.0 keys translated.
- `config.yml`: Server configuration with `default_language: ru`.

### Installation

1. Copy `messages/messages_ru.yml` to `plugins/AuraSkills/messages/messages_ru.yml`.
2. In `plugins/AuraSkills/config.yml` set `default_language: ru`.
3. Or download the pre-built `.jar` from [Releases](https://github.com/milkycloud-dev/auraskills-full-russian-localization/releases/latest).

### Releases

Pre-built ready-to-use binaries (`.jar` / `.zip`) are available for download in [Releases](https://github.com/milkycloud-dev/auraskills-full-russian-localization/releases/latest).

## Русский

### Описание

Репозиторий содержит чистые файлы русской локализации для **AuraSkills v2.4.0 (ArchyX)**.
В состав включены исключительно файлы конфигурации и переводов, без бинарных сборок, с соблюдением требований лицензий авторов.

### Файлы

- `messages/messages_ru.yml`: Полный файл сообщений со всеми 82 новыми ключами v2.4.0.
- `config.yml`: Конфигурация сервера с русским языком по умолчанию (`default_language: ru`).

### Установка

1. Скопируйте файл `messages/messages_ru.yml` в `plugins/AuraSkills/messages/messages_ru.yml`.
2. В `plugins/AuraSkills/config.yml` установите `default_language: ru`.
3. Либо скачайте готовую сборку `.jar` из раздела [Releases](https://github.com/milkycloud-dev/auraskills-full-russian-localization/releases/latest).

### Релизы

Готовые собранные бинарные пакеты (`.jar` / `.zip`) доступны для загрузки в разделе [Releases](https://github.com/milkycloud-dev/auraskills-full-russian-localization/releases/latest).
