## English

### Overview

This repository provides clean, standalone Russian localization files for **AuraSkills v2.4.0 (ArchyX)**.
It contains only configuration and text files to respect original author licensing and copyright requirements.

### Files

- `messages/messages_ru.yml`: Full Russian messages file with all 82 new v2.4.0 keys translated (traits, armor modifiers, stat_info menu).
- `config.yml`: Server configuration with `default_language: ru` and client language detection enabled.

### Installation

1. Copy `messages/messages_ru.yml` to your server folder: `plugins/AuraSkills/messages/messages_ru.yml`.
2. In `plugins/AuraSkills/config.yml`, set `default_language: ru`.
3. Run `/skills reload` or restart your server.

## Русский

### Описание

Репозиторий содержит чистые файлы русской локализации для **AuraSkills v2.4.0 (ArchyX)**.
В состав включены исключительно файлы конфигурации и переводов, без бинарных сборок, с соблюдением требований лицензий авторов.

### Файлы

- `messages/messages_ru.yml`: Полный файл сообщений со всеми 82 новыми ключами v2.4.0 (черты, модификаторы характеристик, меню stat_info).
- `config.yml`: Конфигурация сервера с русским языком по умолчанию (`default_language: ru`) и автоопределением языка клиента.

### Установка

1. Скопируйте файл `messages/messages_ru.yml` в папку сервера `plugins/AuraSkills/messages/messages_ru.yml`.
2. В файле `plugins/AuraSkills/config.yml` укажите `default_language: ru`.
3. Выполните команду `/skills reload` или перезапустите сервер.
